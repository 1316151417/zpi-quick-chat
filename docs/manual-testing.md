# macOS 人工验收

自动测试始终隐藏窗口、禁用原生采集和全局快捷键。下面的系统行为需在实际桌面验证，尚未由自动测试代替：

1. 从其他应用按 Option+Space，确认屏幕下方出现 360×44 输入条和输入焦点；Esc 隐藏后返回来源应用。连续显示/隐藏和空闲后重开应即时响应。
2. 草稿和图片隐藏后保留；Option+Shift+Space 停止旧回复并清空，新内容不混入旧会话。可见大窗中新建保持 660×560；隐藏后新建恢复输入条；空白大窗隐藏后重开折叠，有草稿时保留大窗。
3. 在浮窗已显示但另一个应用有焦点时重新唤起，再隐藏，确认返回最近的来源应用。
4. 跨 Space 和全屏应用使用显示、新建与隐藏快捷键。
5. Option+Shift+C：检查辅助功能权限拒绝、复制未发生、目标应用切换和有效选区；内容只进入草稿。
6. Option+Shift+V：分别带入文字、图片、空剪贴板；图片优先于伴随文字。
7. Option+Shift+A：正常截图、取消截图、权限拒绝与临时文件清理。
8. CLI Ctrl+C 退出后，确认不再响应快捷键、没有残留子进程。
9. 设置 DEEPSEEK_API_KEY 后做真实 DeepSeek 文本、图片和 low 思考请求；不将密钥放进截图或测试日志。
10. 输入条无图钉，点击其他应用立即隐藏，外部不应有原生矩形边框。展开后的对话窗默认不固定，失焦即隐藏；手动点击右上角图钉后失焦保留，Esc 和 Option+Space 仍能隐藏，再次点击图钉恢复失焦隐藏。新会话和重启后均不自动固定，旧的持久化偏好不生效。
11. 选区/剪贴板带入已有草稿后，直接输入应接在末尾；粘贴长文自动增高、滚动到光标，删除后收缩。中文输入法 Enter 确认候选和 Esc 取消候选不得误发送或隐藏。
12. 逐行输入、Shift+Enter 换行、连续回车、图片尚未读完时发送、多轮回复后向上阅读；确认不重复发送、不丢图、不强制滚回底部，消息区和输入区滚动条均为透明轨道、圆头滑块。
13. 从输入条分别预览横图、长图：临时放大为 660×560，图片完整等比显示，无矩形遮罩残留；Esc 和关闭按钮均恢复原输入条高度、草稿和图片，预览中新建不混入旧预览状态。浅色、深色下检查对话窗四角，圆角之外应完全透明。
14. 发送按钮左侧的联网、本机工具默认关闭且可独立切换；空白内容发送失败后仍可更改，首条消息接受后隐藏，后续消息沿用已选工具，新建后恢复关闭。多行草稿时两图标与发送按钮底部对齐，不改变单行输入条的 360×44 尺寸。
15. 从任意目录启动 CLI，开启本机工具后查看图标悬停的 cwd，应始终默认为用户主目录 `~/` 的绝对路径，并让模型运行 `pwd` 核对；终端命令和结果可展开，运行长命令时停止或新建，确认旧进程结束、旧结果不混入新会话。
16. 开启联网后执行搜索与网页读取，确认来源链接可在默认浏览器打开；工具关闭时不提供该能力，来源中的非 HTTP/HTTPS、内网地址和带凭据网址均不打开。联网开关控制搜索工具，不限制 Bash 自行联网。
17. 普通、联网和本机工具会话均由 SDK 默认提供主目录 cwd，上下文不额外重复拼接工作目录提示。本机工具开关同时控制 Bash 命令执行和 Read 文件读取能力。联网过程显示查询/网页和结果数量，终端可展开，本地读取显示文件路径。正常完成后整个过程收起，最后一段回答仍显示，展开回看后刷新状态不应再次强制收起；停止及错误保留过程展开。
18. 检查 Markdown 标题、粗体、嵌套列表、引用、表格、未闭合代码围栏及代码复制；HTML 不执行，远程图片不自动加载。长用户消息默认显示 120px，可展开和收起，并可复制完整输入。
19. 复制按钮后的“来源”入口应打开浮窗，展示本次搜索/读取的真实、去重来源；正文不再重复附来源列表。浮窗不超出窗口，Esc 先关闭来源，点击输入区关闭浮窗，新建清空来源。生成长文时向上滚动小于 80px 也不能被新输出拉回；回到底部后继续自动跟随。
20. 发出普通或工具请求后，立即显示“工作中 N 秒”、分隔线及旋转加载图标，首字输出前耗时也持续更新。完成后停止计时，操作栏顺序为复制、来源（有时）、回答时间；当日显示 HH:mm，悬停可查看完整日期时间。
21. 连续执行超过 12 轮工具调用后，任务仍可完成并在原会话继续追问；长命令停止后不再执行后续动作，仍可继续同一会话。若 SDK 确实异常退出，输入区应同时显示具体原因与新建对话提示，不能只剩泛化的“会话已结束”。
22. 开启本机工具后，分别让助手按绝对路径、`~/` 路径读取图片，以及查找指定目录中的最新截图后读取；使用带有随机文字、数字和颜色的测试图片核对真实识图效果。过程应先展示查找命令、再展示读取路径和缩略图，点击可预览，Esc 返回对话；继续追问无需再次带入图片。缺失文件应展示读取错误，仍可继续对话；新建后清空路径和缩略图。本机工具关闭或仅联网时不提供 Read。
23. 分别拖拽输入条和大窗口，Esc、失焦或 Option+Space 隐藏后再次唤起，应恢复各自最后位置；鼠标移到其他屏幕后再次唤起也不重置拖拽位置。输入条多行增高和收缩保持底边，图片预览关闭、新建后回到输入条时保留输入条的位置。断开原屏幕或缩小工作区后，窗口仍完整可见；退出程序后重新启动恢复默认位置。

实现对照 ZPI 提交 `4d83b67`、`520ab82`、`804e1a3`：保持窗口常驻，关闭后台渲染节流；新会话同步清空并发布，再独立等待旧请求清理；普通唤起不克隆/重发历史；仅尺寸或模式变化时调整原生窗口。自动测试覆盖同步重置、取消与迟到结果隔离、真实 Electron 输入尺寸与光标、逐段 SSE、消息节点复用。隐藏测试的 IPC 时序不能代替实体全局快捷键在 Cocoa 回调中的端到端延迟，应在同机使用上述序列复测。
